# Employee Portal System

## Project Overview
Employee Portal is a smart HR management system that helps organizations manage employees, leave requests, and payroll calculations in one platform.

## Problem Statement
Companies need an efficient system to manage employee information, check leave eligibility, and calculate payroll. Manual processes take time and can cause errors.

## Solution
This project provides:
- Employee management
- Leave eligibility checking using AI-based recommendations
- Payroll calculation with salary insights

## Features

### Employee Management
- View employee details
- Manage employee information

### AI Leave Eligibility Checker
- Checks available leave balance
- Validates requested leave days
- Provides recommendation based on company policy

### AI Payroll Calculator
- Calculates gross and net salary
- Includes bonus, overtime, and deductions
- Provides salary insights
